# WL-1 Smart Instructor V6 — source code

نسخة Flutter تعليمية للتجربة على iOS وAndroid وWindows. لا تتضمن أي مراجع طائرة أو أسرار تشغيل داخل المستودع.

## اتفاقات الواجهة

1. **Study:** يعرض ملف PDF الأصلي كما هو، بكل صفحاته ورسوماته وباللغة الإنجليزية الأصلية، دون ترجمة أو إعادة ترتيب أو اختصار. يفتح مرجع الـPDF في `PdfViewer.file`، مع الاحتفاظ بنسخة محلية منه.
2. **Ask Instructor:** الشرح من نموذج محلي GGUF باللغة العربية المصرية. يسترجع نصوصًا من صفحات المرجع ويربطها بالصفحة. يتذكر جزءًا من سياق الحوار ليقبل أسئلة المتابعة مثل «ليه؟». إذا لم يوجد نموذج GGUF، يعرض المقتطفات الأصلية فقط، ولا يدّعي أنها إجابة ذكاء اصطناعي.
3. **Quiz:** واجهة الاختبار والأسئلة والإجابات والتصحيح كلها إنجليزية، واتجاه النص من اليسار لليمين. الأسئلة المتاحة الآن تجريبية عن مبادئ الكهرباء، وليست امتحانًا مولدًا من مراجع الطائرة.
4. **References:** إضافة ملفات PDF وTXT وJSON على الجهاز، وتعديل حالتها أو حذفها بالباسورد. ملفات PDF المصوّرة تفتح بصفحاتها الأصلية، لكن يلزم OCR منفصل للبحث في نصها.

## تشغيل البرنامج على iPhone

يلزم Mac عليه Flutter وXcode وتوقيع Apple، لإنشاء هيكل Flutter وتشغيل المصدر.

```bash
flutter create --platforms=ios,android,windows .
flutter config --enable-swift-package-manager
flutter pub get
flutter run -d <your-iphone-device-id>
```

للاستخدام دون إنترنت بعد التثبيت: استورد PDF مسموح باستخدامه من تطبيق Files، واستورد GGUF متوافقًا مع الجهاز ومصرحًا باستخدامه. استيراد كل الملفات محلي. يحتاج بناء iOS إلى دعم SwiftPM وربما إعداد حد النظام إلى iOS 16.4 أو أعلى، وفق مكتبات المحرك.

### حدود التنفيذ

- لم نختبر تشغيل هذه النسخة على iPhone فعلي لأن بيئة العمل لا تحتوي على Mac وXcode وFlutter.
- يتم البحث بالكلمات ومرادفات محدودة؛ ليس بحثًا دلاليًا كاملًا بين العربي والإنجليزي.
- أداء نموذج الذكاء والذاكرة يحتاج اختبار على أجهزة الضباط.
- لا ترفع ملفات المراجع الحساسة أو GGUF إلى GitHub. المكتبة المحلية تحفظها على الجهاز فقط.
- لم يُعتمد بعد إصدار تثبيت iOS ولا توزيع رسمي للضباط.
- حماية الباسورد محلية وليست حاجزًا ضد تعديل مالك الجهاز نفسه للملفات.

## معاينة HTML

ملف `preview.html` هو معاينة للواجهة يمكن فتحها في المتصفح. يعرض PDF الأصلي من ملف تختاره أنت، واختبارًا بالإنجليزية، وحماية إدارة تجريبية. لا يشغّل نموذج AI محليًا ولا يُعد بديلًا عن التطبيق الأصلي. الملفات المختارة في المعاينة لا تحفظ بين جلسات إعادة التحميل.
