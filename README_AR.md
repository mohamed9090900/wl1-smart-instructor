# WL-1 Smart Instructor

تطبيق تعليمي محلي. الهدف الأساسي هو أن يسأل المستخدم عن نقطة غير واضحة، ثم يشرحها المدرس بالعربية المصرية اعتمادًا على مراجع محفوظة على الجهاز.

## شكل التطبيق المعتمد

التطبيق يحتوي على قسمين فقط:

1. **المدرس الذكي** — الشاشة الرئيسية، وتبدأ بها المحادثة مباشرة.
2. **المراجع** — إضافة الملفات محليًا وإدارتها ومراجعتها. يستخدم المدرس النصوص المفهرسة ويعرض اسم المرجع ورقم الصفحة.

لا توجد شاشة دراسة منفصلة أو اختبارات في النطاق الحالي. الكتب تظل بلغتها وصفحاتها الأصلية عند فتح ملفات PDF.

## ما تنفذه نسخة V6 حاليًا

- واجهة Flutter بخلفية رمادي فاتح مائل للأزرق وبقسمي المدرس والمراجع.
- استيراد PDF وTXT وJSON إلى مساحة التطبيق المحلية.
- استخراج نص PDF القابل للبحث وتخزين أرقام الصفحات. ملفات PDF المصورة لا تُفهرس دون OCR.
- بحث محلي بالكلمات مع قاموس محدود لبعض المصطلحات العربية والإنجليزية.
- تشغيل نموذج GGUF محليًا عبر `llamadart` عند إضافته من قسم المراجع.
- إرسال المقاطع المسترجعة وسياق المحادثة إلى النموذج، مع طلب صريح منه ألا يضيف معلومات خارج النص.
- عرض المراجع والصفحات المرتبطة بجواب المدرس.
- إدارة الملفات محمية بكلمة مرور محلية. لا توجد حسابات أو اتصال بخادم.

هذه وظائف أولية. النموذج الحقيقي وجودة الإجابات لم يُختبرا على iPhone. البحث الحالي قائم على الكلمات وليس بحثًا دلاليًا. لا يحتوي المستودع على نموذج GGUF أو كتب الطائرة.

## معاينة HTML

`preview.html` يعرض شكل قسمي المدرس والمراجع. لا يشغل نموذجًا، ولا يحفظ الملفات بعد إغلاق الصفحة، ولا يمثل نسخة iOS قابلة للتثبيت.

## التحقق والبناء

يتطلب البناء Flutter SDK. يجهز سير العمل في GitHub هيكل المنصات ويشغل تحليل Flutter واختبارات البحث. بناء iOS غير الموقّع يحتاج بيئة macOS وXcode. إضافة نموذج GGUF الحالي تتطلب iOS 16.4 أو أحدث. تثبيت نسخة على جهاز فعلي يحتاج توقيع Apple؛ لا يوجد حاليًا IPA جاهز للتثبيت. لا يوجد حاليًا IPA جاهز للتثبيت.

```bash
flutter create --platforms=ios,android,windows .
flutter pub get
flutter analyze
flutter test
```

## الملفات المحلية والخصوصية

- لا ترفع كتبًا أو مراجع فنية أو ملفات نماذج أو بيانات تشغيل إلى GitHub.
- أضف المراجع والنموذج من داخل التطبيق على الجهاز.
- كلمة مرور المسؤول مخزنة محليًا بعد اشتقاقها باستخدام PBKDF2. هذه حماية لإدارة التطبيق وليست تشفيرًا للكتب أو حاجزًا ضد مالك الجهاز.
- لا يسجل التطبيق حسابات شخصية أو درجات.
